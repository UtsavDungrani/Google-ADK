CloudPlatform - API Reference and Integration Guide

Base URL and Authentication

Base URL: https://api.cloudplatform.example.com/v1

Authentication: Authenticate all requests using Authorization Bearer token header:

Authorization: Bearer YOUR_API_SECRET_KEY

Endpoint: List Projects (GET /projects)

Method: GET /projects

Query Parameters: limit (integer, default: 20, max: 100), status (active, archived)

Response Example:

{

"status": "success",

"data": [

{

"id": "proj_99812",

"name": "ecommerce-backend",

"status": "active",

"created_at": "2026-01-15T09:00:00Z"

}

]

}

Endpoint: Trigger Deployment (POST /projects/{project_id}/deploy)

Method: POST /projects/{project_id}/deploy

Request Body:

{

"branch": "main",

"commit_sha": "a1b2c3d4",

"environment": "production"

}

Response Example:

{

"status": "success",

"deployment_id": "dep_456789",

"build_url": "https://dashboard.cloudplatform.example.com/deployments/dep_456789"

}

Webhooks & Event Subscriptions

Register webhooks to receive real-time notifications for deployment events:

• Supported events: deployment.started, deployment.succeeded, deployment.failed

• Webhook payloads include HMAC-SHA256 signature in X-CloudPlatform-Signature header for verification.
